# Trifold brand kit

**Trifold** — define an operation once, ship it as HTTP, CLI, and MCP.

## System

| Role | File | Use |
|------|------|-----|
| **Primary mark** | `primary/trifold-mark.png` | Closed denim wallet + peeking cards (hero / default) |
| **Open wallet** | `variants/trifold-wallet-open.png` | Alternate mark with three surface cards |
| **Avatar** | `variants/trifold-avatar.png` | GitHub avatar / circular badge |
| **Splash** | `variants/trifold-splash.png` | CLI welcome, stickers, fun moments |
| **Favicon** | `variants/trifold-favicon.png` | Tiny UI / browser tab |

## Concept

Doodle-style **denim trifold wallet**. Three cards / folds = three surfaces (CLI, HTTP, MCP). Indigo denim undertones, cream contrast stitching, copper hardware.

## Palette

| Name | Hex | Role |
|------|-----|------|
| Indigo denim | `#1E3A5F` | Wallet body, wordmark |
| Washed denim | `#3B6EA5` | Mid tones, tagline |
| Chambray | `#7BA3C9` | Soft accents |
| Cream stitch | `#F5F0E6` | Stitching |
| Copper | `#B87333` | Rivets / snap |

## Tagline

**One op. Three surfaces.**

## Don’t

- Don’t lose the denim + stitch language
- Prefer the closed-wallet primary for GitHub avatar; splash is for fun moments only
